# CBIO012 "The Usage of Gene Synergy to Predict Drug Synergy" - preregistration (before any model scored)
Replication-style benchmark, no novelty claim. Interprets "gene synergy" as gene-level relationships between the two drugs' target gene sets (network links, shared pathways, overlap), used to predict drug-combination synergy. No gene-gene synergy screen (e.g. double-CRISPR) is used; stated.
Data: O'Neil/Merck screen as distributed with DeepSynergy: 23,052 drug-pair x cell-line rows, 38 drugs, 39 cell lines, Loewe synergy score (label synergistic = score >= 10, ~35% positive). Drug targets from Hetionet v1.0 CbG edges. Only 24 of 38 drugs map to Hetionet (list in manifest); the other 14 (mostly investigational Merck compounds) have no target features. SN-38 is mapped to irinotecan (prodrug proxy). No cell-line expression features are used (not downloaded; 424 MB pickle exceeds memory), so cell-line effects are identity only.
Features per pair (symmetric): drug identity (summed one-hot); cell line one-hot; GENE features (when both drugs mapped): number of targets (sum, product), Jaccard of target sets, count of Hetionet gene-gene links (GiG, Gr>G) between the two target sets, Jaccard of target-pathway sets (GpPW), 16-d SVD of target-gene profile (sum and abs difference).
Models: B1 = cell-line mean + drug-identity effects (logistic regression on identity features only). M = HistGradientBoosting on identity + gene features. Gene-feature gain = M(identity+gene) minus M(identity only), same model class, evaluated on the SUBSET where both drugs are mapped (n reported).
Splits (5 folds each, seeds fixed): random rows; cold-pair (a drug pair with all its cell lines held out); cold-cell-line; cold-drug (a drug and every pair containing it held out; per mapped drug).
Gates: D3 cold-pair: AUROC gain from gene features >= +0.01 (mean over folds). D7 shuffle control: gene features permuted across drug pairs should give gain <= 0.01.
Directions: D1 data and mapping stats; D2 random-split baselines and gene gain; D3 cold-pair gain (gate); D4 cold-cell-line gain; D5 cold-drug gain (mapped drugs); D6 feature-group ablation (overlap, network links, pathway, SVD); D7 shuffled gene features; D8 per-cell-line AUROC spread (cold-pair); D9 label-threshold sensitivity (5, 10, 20); D10 regression: Pearson r of Loewe score on cold-pair with/without gene features.
Not run: chemical-structure features, cell-line expression, deep nets.
